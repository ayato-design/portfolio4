# LP型企業サイト

## 概要
前作のLP型企業サイトを参考に、HTML/CSS/JavaScriptを用いてデザイン違いで制作しました。
レスポンシブ対応を行い、スマホでも閲覧し易いよう調整しています。

## 制作目的
- Figmaの操作練習の為
- HTML/CSSでのレイアウト構築に慣れる為
- JavaScript/jQueryを使った動きを実装する為
- 実務でありそうなレスポンシブ対応を意識する為

## 使用技術
- HTML
- CSS
- JavaScript(basic)
- jQuery
- Figma
- Canva

## オリジナルで考えた部分
- 配色
- 余白
- ボタンや見出しデザイン
- スマホ時の見せ方
メニュー部分以外は全て考えました。
ニュースページやコンタクトページは過去の作品を流用しています。
見出しデザインは前回の作品をアレンジしています。

## 工夫した点
- Google mapの導入
- 技術と知識向上の為、画像加工(斜めカット加工)はCSSで行いました
- レスポンシブデザイン時のAboutエリアの見え方工夫
- CSSを重くさせないように、流用(再利用)を意識しました

## 苦労した点・解決方法
- レスポンシブデザイン作成に不慣れな為、バランス調整が大変でした
- わからない部分は書籍やネットで検索して解決しました
- それでもわからない場合は、AI(Copilot)を使用して解決しました

## 今後改善したい点
- レスポンシブデザイン時のAboutエリアの見え方調整
- お借りしたコードを自分で書けるように勉強
- CSSの流用(再利用)をもっと増やしたい
